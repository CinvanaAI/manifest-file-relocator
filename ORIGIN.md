# Origin

This project comes from a May 2026 script named `mover.py` used in a classification workspace. The original supported multiple instruction files, individual filenames, globs, extensions, and a convenient image type.

The public continuation preserves those useful selection ideas while replacing the unsafe execution model. It does not copy the original personal folder names, instruction files, classification outputs, or path assumptions. Planning, content-addressed approval, global preflight, verified transfer, durable journals, rollback, containment, and synthetic tests are new public hardening.
